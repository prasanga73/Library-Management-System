# Library Management System
This is a library management system created using relational database which is the primary focus of this project. The UI is created in python using tkinter which is further enhanced by finishing touches with ttkbootstrap. Different CRUD concepts were visited and assessed to broaden the horizon of database knowledge. The tools used are: <br>

<li>MySQL connector</li>
<li>Tkinter</li>
<li>Ttkbootstrap</li>
<li>MySQL</li>
